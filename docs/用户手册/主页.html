1. 主页

设备开机后进入的第一个页面 · 2 行 3 列应用宫格

页面说明

  • 顶部状态栏：左侧 WiFi / 录制等状态图标，中央实时时钟与日期，右侧电池电量
  • 六个应用入口，按 2 行 3 列排布： 第一行 拍照 · AI 拍照 · 相册， 第二行 AI 对话 · 测试页面 · 设置
  • 当前选中的应用图标带高亮框；按方向键移动选中项，按 OK 进入
  • 下方为移动选中项后的效果（第二行选中「设置」）：

按键操作

正常＝本页可用 灰色＝本页无响应
按键功能
上 选中项移到上一行（第二行 → 第一行；已在第一行时无动作）
下 选中项移到下一行（第一行 → 第二行；已在第二行时无动作）
左 选中项在同一行内向左移动一格（已在最左列时无动作）
右 选中项在同一行内向右移动一格（已在最右列时无动作）
OK 进入当前选中的应用：
拍照 → 拍照模式 · AI 拍照 → AI 拍照（自动切 12M） · 相册 → 照片九宫格
AI 对话 → 对话页 · 测试页面 → 测试菜单 · 设置 → 系统设置
电源 本页无功能（电源键为全局按键：短按亮/熄屏，长按 3 秒关机）
快门 本页无响应
对焦 本页无响应
变焦 T 本页无响应
变焦 W 本页无响应
MODE 本页无响应
MENU 本页无响应（主页已是顶层，无更上级可返回）
AI 键 本页无响应
说明：灰色按键并非故障——主页只注册了方向键与 OK 共 5 个按键的响应， 其余按键在本页设计上就不做任何事。电源键虽在本页无页面级功能， 但其亮/熄屏与关机作用是全局的，在任何页面都生效。
