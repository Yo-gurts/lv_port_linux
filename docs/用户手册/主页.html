1 使用说明

1）本手册截图均由 SDL 模拟器自动抓取，为无鼠标光标的纯 UI 画面，与设备实机画面一致。

2）按键操作表：每个按键配图标与作用说明；灰色按键表示在本页面无响应。

3）灰色判定标准：该按键在本页未注册任何按键回调（电源键除外——其亮/熄屏与关机作用是全局的，任何页面都生效）。

4）本册当前仅含「主页」章节（打样），其余页面将按同一格式补充。

2 按键布局总览

整机按键布局（截图自「按键测试」页面）

1）整机共 13 个按键：电源、AI 键、变焦 T/W、对焦、快门、MODE、MENU、上/下/左/右/OK。

2）按键图标与「按键测试」页布局图一一对应，本手册各章沿用同一套图标。

3 主页

设备开机后进入的第一个页面，2 行 3 列应用宫格。

3.1 页面说明

主页默认状态（第一行第一列「拍照」选中）

1）顶部状态栏：左侧 WiFi / 录制等状态图标，中央实时时钟与日期，右侧电池电量。

2）六个应用入口按 2 行 3 列排布：第一行 拍照 · AI 拍照 · 相册；第二行 AI 对话 · 测试页面 · 设置。

3）当前选中的应用图标带高亮框，按方向键移动选中项，按 OK 进入。

按「下 + 右 + 右」后：第二行「设置」选中

3.2 按键操作

图例：OK ＝本页可用；OK ＝本页无响应

按键功能
上选中项移到上一行（第二行 → 第一行；已在第一行时无动作）
下选中项移到下一行（第一行 → 第二行；已在第二行时无动作）
左选中项在同一行内向左移动一格（已在最左列时无动作）
右选中项在同一行内向右移动一格（已在最右列时无动作）
OK进入当前选中的应用：拍照 / AI 拍照 / 相册 / AI 对话 / 测试页面 / 设置
电源本页无功能（电源键为全局按键：短按亮/熄屏，长按 3 秒关机）
快门本页无响应
对焦本页无响应
变焦 T本页无响应
变焦 W本页无响应
MODE本页无响应
MENU本页无响应（主页已是顶层，无更上级可返回）
AI 键本页无响应

灰色按键并非故障：主页只注册了方向键与 OK 共 5 个按键的响应，其余按键在本页设计上不做任何事。
